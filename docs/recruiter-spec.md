## 模块 1：招聘者注册

### 功能描述
三步注册流程：① 手机验证 → ② 企业信息填写 → ③ 提交审核（需管理员审批）

### 页面：`recruiter/registration.vue`
**步骤 1 — 手机验证**
- 手机号输入 + 获取验证码（60s 倒计时）
- 验证码正确后进入步骤 2

**步骤 2 — 企业信息**
- 企业名称（必填）
- 统一社会信用代码（必填，18位校验）
- 职位/岗位名称（必填）
- 企业简介（选填，文本域）
- 所在城市（选填，城市选择器）

**步骤 3 — 提交审核**
- 显示"审核中"状态页
- 说明文案：审核通常在 1 个工作日内完成
- 返回首页按钮

### API
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/auth/recruiter/register` | 提交企业注册信息，返回待审核状态 |
| GET | `/auth/recruiter/status` | 查询审核状态（PENDING / APPROVED / REJECTED） |

### 测试用例

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|----|------|---------|------|---------|
| R1-01 | 正常完成注册 | 未注册手机号 | 填写全部信息提交 | 跳转审核中页面，状态为 PENDING |
| R1-02 | 手机号已存在 | 手机号已注册为 SEEKER | 输入该手机号 | 提示"该手机号已注册为求职者账号" |
| R1-03 | 信用代码格式错误 | — | 输入17位或含非法字符 | 表单校验提示，不允许提交 |
| R1-04 | 重复提交 | 已提交过审核 | 再次访问注册页 | 直接显示当前审核状态 |
| R1-05 | 管理员审批通过 | 状态 PENDING | 管理员后台通过 | 招聘者可正常登录，角色为 RECRUITER |
| R1-06 | 管理员拒绝 | 状态 PENDING | 管理员后台拒绝 | 用户看到拒绝原因，可重新提交 |

## 模块 2：招聘者首页

### 功能描述
数据看板 + 快捷入口：展示职位数量、收到简历数、面试邀请数；快速跳转各功能模块

### 页面：`recruiter/index.vue`
**顶部信息区**
- 企业名称 + 招聘者姓名/职位
- 企业认证徽章（APPROVED 显示蓝色认证，否则显示审核中）

**数据看板**
- 在招职位数
- 本周收到简历数
- 待处理简历数（未查看）
- 已发出面试邀请数

**快捷入口**
- 发布职位 → `recruiter/jobPosting`
- 找人才 → `recruiter/talents`
- 简历中心 → `recruiter/resumeCenter`
- 职位管理（管理现有职位列表）

### API
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/recruiter/dashboard` | 返回看板统计数据 |
| GET | `/recruiter/profile` | 返回企业信息 + 审核状态 |

### 测试用例

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|----|------|---------|------|---------|
| R2-01 | 正常加载首页 | 已登录 RECRUITER（13800000002） | 进入首页 | 显示企业名、看板数据均为真实值（非0、非空） |
| R2-02 | 零数据状态 | 新注册招聘者，无职位 | 进入首页 | 看板全部显示 0，无崩溃 |
| R2-03 | 认证状态显示 | 企业未审核通过 | 进入首页 | 显示"审核中"徽章而非认证标志 |
| R2-04 | 快捷入口跳转 | — | 点击各入口 | 正确跳转对应页面 |

## 模块 3：找人才

### 功能描述
主动搜索求职者：关键词搜索 + 多维度筛选（城市、学历、工作性质）+ 候选人卡片列表

### 页面：`recruiter/talents.vue`
**搜索栏**
- 关键词输入（职位名、技能等）
- 清空后展示全量候选人

**筛选区（可折叠）**
- 城市选择
- 学历要求（下限）
- 求职意向（全职/兼职/实习）
- 工作年限区间

**候选人列表**
- 卡片：头像占位、姓名（脱敏：张*）、当前职位、公司、学历、城市
- 信用徽章（如有认证记录）
- 点击进入简历详情

**分页**
- 滚动加载更多（page + limit）

### API
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/recruiter/seekers` | 候选人列表，支持 keyword/city/degree/nature/page/limit |
| GET | `/recruiter/seekers/:userId` | 单个候选人简历详情（权限：RECRUITER） |

### 测试用例

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|----|------|---------|------|---------|
| R3-01 | 无筛选加载列表 | 有求职者账号且简历有内容 | 进入找人才页 | 列表加载候选人，姓名脱敏显示 |
| R3-02 | 关键词搜索 | — | 输入"软件" | 仅展示相关职位/技能包含该词的候选人 |
| R3-03 | 城市筛选 | — | 选择"成都" | 仅展示目标城市为成都的候选人 |
| R3-04 | 学历筛选 | — | 选择"本科及以上" | 仅展示 BACHELOR / MASTER / DOCTOR |
| R3-05 | 组合筛选 | — | 城市+学历+关键词 | 结果满足所有筛选条件 |

## 模块 4：职位管理

### 功能描述
查看和管理已发布职位：在线/下线切换、编辑、删除

### 入口：`recruiter/index.vue`（独立 tab 或跳转列表）
**职位列表**
- 职位名称 + 城市 + 薪资
- 状态标签：招聘中（ACTIVE）/ 已下线（CLOSED）/ 审核中（PENDING）
- 投递数量角标

**操作**
- 上线/下线切换（Toggle）
- 编辑 → 跳转 `recruiter/jobPosting?id=xxx`（复用发布页）
- 删除（二次确认弹窗）

### API
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/jobs/mine` | 当前招聘者的职位列表 |
| PATCH | `/jobs/:id/status` | 更新职位状态（ACTIVE / CLOSED） |
| DELETE | `/jobs/:id` | 删除职位（软删除） |

### 测试用例

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|----|------|---------|------|---------|
| R4-01 | 查看职位列表 | 有已发布职位 | 进入职位管理 | 列表显示所有职位及状态 |
| R4-02 | 下线职位 | 职位状态 ACTIVE | 点击"下线" | 状态变为 CLOSED，求职端不再显示该职位 |
| R4-03 | 重新上线 | 职位状态 CLOSED | 点击"上线" | 状态变为 ACTIVE，求职端重新可见 |
| R4-04 | 删除职位 | 职位存在 | 点击删除并确认 | 职位从列表消失，已投递记录保留 |
| R4-05 | 取消删除 | — | 点击删除后取消 | 职位不变 |
| R4-06 | 编辑跳转 | — | 点击编辑 | 跳转发布页，表单预填当前职位信息 |

## 模块 5：发布/编辑职位

### 功能描述
发布新职位或编辑已有职位（通过 `id` 参数区分新建/编辑）

### 页面：`recruiter/jobPosting.vue`
**表单字段**
- 职位名称（必填）
- 工作性质（全职/兼职/实习）
- 薪资范围（起止 + 单位：元/月、元/天、元/小时）
- 工作城市（城市选择器）
- 详细地址（选填）
- 最低学历要求
- 工作描述（富文本/文本域，必填）
- 招聘人数（数字输入）

**发布/保存**
- 新建：POST 创建职位，审核通过后 ACTIVE
- 编辑：PATCH 更新，修改后如涉及核心字段可能重新进入 PENDING

### API
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/jobs` | 发布新职位 |
| GET | `/jobs/:id` | 获取职位详情（编辑预填） |
| PATCH | `/jobs/:id` | 更新职位信息 |

### 测试用例

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|----|------|---------|------|---------|
| R5-01 | 发布完整职位 | — | 填写所有字段提交 | 职位创建成功，出现在职位列表 |
| R5-02 | 必填字段空缺 | — | 不填职位名称提交 | 表单校验报错，阻止提交 |
| R5-03 | 薪资范围合法性 | — | 最低薪资 > 最高薪资 | 校验提示"最低薪资不能高于最高薪资" |
| R5-04 | 编辑已有职位 | 职位 id 存在 | 带 id 参数进入发布页 | 表单预填该职位所有字段 |
| R5-05 | 编辑后保存 | — | 修改职位名称后保存 | 列表和详情页均显示新名称 |
| R5-06 | 字数限制 | — | 工作描述超出上限 | 提示超出，不允许提交 |

## 模块 6：简历中心（列表）

### 功能描述
管理收到的所有投递简历：Tab 分类 + 快速处理（邀请面试/标记不合适）

### 页面：`recruiter/resumeCenter.vue`（重构为列表）
**Tab 分类**
- 待处理（PENDING）
- 已邀请（INTERVIEW）
- 通过（ACCEPTED）
- 不合适（REJECTED）

**候选人卡片（每个 Tab 共用）**
- 姓名（脱敏）+ 当前职位 + 公司
- 投递时间
- 应聘职位名称
- 操作：查看简历 → 跳转 `resumeDetail`；邀请面试（仅待处理 Tab）；标记不合适

**分页**：滚动加载

### API
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/recruiter/deliveries` | 收到的投递列表，status 筛选 |
| PATCH | `/recruiter/deliveries/:id/status` | 更新投递状态（INTERVIEW / ACCEPTED / REJECTED） |

### 测试用例

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|----|------|---------|------|---------|
| R6-01 | 加载待处理简历 | 有求职者投递该企业职位 | 进入简历中心 | 待处理 Tab 显示对应候选人卡片 |
| R6-02 | Tab 切换 | — | 点击"已邀请" Tab | 仅显示状态为 INTERVIEW 的投递 |
| R6-03 | 标记不合适 | 待处理投递存在 | 点击"不合适" | 该卡片从待处理消失，出现在不合适 Tab |

| R6-05 | 空 Tab | 无该状态投递 | 切换到空 Tab | 显示"暂无记录"空态 |
| R6-06 | 跳转简历详情 | — | 点击候选人卡片 | 跳转 `resumeDetail` 页，显示完整简历 |

## 模块 7：简历详情 + 面试邀请

### 功能描述
查看单个候选人完整简历，并可发出面试邀请

### 页面：`recruiter/resumeDetail.vue`（新建）
**简历内容区**
- 基本信息：姓名（脱敏）、性别、年龄、当前城市
- 自我描述
- 教育经历（学校、专业、时间段）
- 工作经历（公司、职位、时间段、工作内容）
- 项目经历
- 技能标签
- 工作信用认证徽章（如有认证记录则展示，状态 APPROVED）

**底部操作栏**
- 分享简历
- 标记不合适
- 索要简历（发送消息）
- **通知面试**（打开面试邀请 Modal）

**面试邀请 Modal（原型 061）**
- 面试方式：线上/线下
- 面试时间（日期时间选择器）
- 面试地点（线下时显示）
- 备注
- 发送按钮

### API
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/recruiter/seekers/:userId` | 获取候选人完整简历（需 RECRUITER 权限） |
| POST | `/recruiter/interview-invite` | 发送面试邀请（创建消息记录 + 更新投递状态） |
| PATCH | `/recruiter/deliveries/:id/status` | 标记不合适 |

### 测试用例

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|----|------|---------|------|---------|
| R7-01 | 查看完整简历 | 候选人有完整简历 | 进入简历详情页 | 工作经历、教育经历、自我描述均正确显示 |
| R7-02 | 简历部分字段为空 | 候选人未填完简历 | 进入简历详情页 | 空字段优雅处理（"暂无"），不崩溃 |
| R7-03 | 信用认证徽章 | 候选人有 APPROVED 工作认证 | 查看简历 | 认证徽章正常显示，点击可查看认证详情 |
| R7-04 | 发送面试邀请（线下） | — | 填写时间、地点发送 | Modal 关闭，候选人收到面试消息，投递状态 → INTERVIEW |
| R7-05 | 发送面试邀请（线上） | — | 选择线上，不填地点 | 发送成功，无地点字段 |
| R7-06 | 面试时间过去 | — | 选择过去的时间 | 表单校验提示"面试时间不能早于当前时间" |
| R7-07 | 标记不合适 | — | 点击"不合适" | 弹出确认，确认后投递状态 → REJECTED |
| R7-08 | 索要简历（消息） | — | 点击"索要简历" | 发送系统消息到候选人聊天，提示已发送 |
