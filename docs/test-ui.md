### F. 岗位详情页（招聘官视角）

## 每次改动后的验证原则

1. **改了哪个页面，就完整走一遍该页面的用例**
2. **改了共享组件（BottomNav/HeaderNav），两个角色都要验证**
3. **凡是有 popup 的页面，必须验证：popup打开时底部按钮是否被遮挡**
4. **新页面必须验证：导航是否正确（能进能出）、数据是否真实渲染（非空/undefined）**
5. **tsc 通过 ≠ 可以报告完成；只有清单打勾才算完成**
